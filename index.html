🔔 Pengaturan Notifikasi

Sistem notifikasi menggunakan Web Push API Native (gratis, unlimited) + ntfy.sh sebagai relay backup. Tidak membutuhkan akun atau SDK pihak ketiga.
📡 ntfy.sh Topic (Relay Backup)
Topic unik untuk outlet ini. Dapur bisa subscribe manual via app ntfy.sh di Android/iOS untuk menerima notifikasi bahkan saat browser tutup.
🔗 Buka ntfy.sh
Cara subscribe di Android/iOS: Install app ntfy → Add Subscription → masukkan topic di atas → pilih server ntfy.sh
🌐 Status Notifikasi Browser
📱 Panduan Setup Notifikasi Dapur
  1. Login sebagai role dapur
  2. Klik tombol "Aktifkan Notifikasi" di halaman KDS
  3. Izinkan notifikasi saat browser meminta
  4. Notifikasi akan muncul via: Firestore real-time (tab aktif) + Browser Push (tab tidak aktif) + ntfy.sh SSE (backup)
  5. Untuk notifikasi saat browser tutup sepenuhnya: install app ntfy di Android/iOS dan subscribe ke topic di atas
